
🚀 AI-Career-Toolkit

*Your AI-Powered Career Growth Companion* | Resume Analysis + YouTube Summarization

An all-in-one AI toolkit designed to supercharge your career journey. From cracking your resume ATS score to summarizing long YouTube tutorials in seconds.

✨ Features

*📄 AI Resume Analyzer*
- Upload resume PDF and get instant ATS Score / 100
- Missing keywords, formatting issues and suggestions
- Built with OpenAI GPT-4

*🎥 AI YouTube Video Summarizer*
- Paste any YouTube link, get transcript + AI summary
- Save hours of watching long tutorials

🛠️ Tech Stack
Python | Streamlit | OpenAI API | Google Gemini | LangChain | PyPDF2

📁 Project Structure
- app.py - Main App
- AI_Resume_Analyzer.ipynb
- AI_YouTube_Video_Summarizer.ipynb
- requirements.txt

⚙️ How to Run Locally
1. git clone https://github.com/mansi-sharma123/AI-Career-Toolkit.git
2. cd AI-Career-Toolkit
3. pip install -r requirements.txt
4. Create.env file and add OPENAI_API_KEY
5. streamlit run app.py

🚀 Deployment - Streamlit Cloud (Recommended)
1. Go to share.streamlit.io and login with GitHub
2. New app -> Select mansi-sharma123/AI-Career-Toolkit
3. Main file: app.py
4. Add your API keys in Secrets
5. Click Deploy!
