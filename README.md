🎯 Problem It Solves

1. Students ka resume ATS me fail ho jata hai
2. 2 ghante ki YouTube tutorial dekhne me time waste hota hai

*Solution:* Ye toolkit 10 seconds me resume ka score aur video ka summary de deta hai.

✨ Features Inside This Repo

📄 AI Resume Analyzer - `AI_Resume_Analyzer.ipynb`
- PDF resume upload karo
- ATS Score / 100 milega
- Missing keywords, skills gap, formatting mistakes batayega
- GPT-4 se improvement suggestions

🎥 AI YouTube Video Summarizer - `AI_YouTube_Video_Summarizer.ipynb`
- Koi bhi YouTube link paste karo
- Automatic transcript fetch
- Gemini / GPT se 5-point summary + key takeaways

💻 Main Web App - `app.py`
- Dono tools ka combined Streamlit app
- Ek hi jagah pe sab kuch use kar sakte ho

📁 Ye Repo Ke Andar Kya Hai

AI-Career-Toolkit/
├── app.py - Main Streamlit Web App (Resume + YouTube)
├── AI_Resume_Analyzer.ipynb - Resume logic ka code
├── AI_YouTube_Video_Summarizer.ipynb - YouTube logic ka code
├── requirements.txt - Saare libraries
└── README.md - Ye file

🛠️ Tech Stack

*Language:* Python
*Frontend:* [Streamlit](https://streamlit.io)
*AI Models:* [OpenAI GPT-4](https://openai.com), [Google Gemini](https://ai.google.dev)
*Framework:* [LangChain](https://www.langchain.com)
*Libraries:* PyPDF2, youtube-transcript-api, python-dotenv

⚙️ Local Setup

Clone repo
git clone https://github.com/mansi-sharma123/AI-Career-Toolkit.git
cd AI-Career-Toolkit

Install
pip install -r requirements.txt

Add API Key -.env file banao
OPENAI_API_KEY=your_key_here

Run
streamlit run app.py

☁️ Deployment

1. Jao [share.streamlit.io](https://share.streamlit.io) par
2. GitHub se login karo
3. New App -> Repo select karo: [mansi-sharma123/AI-Career-Toolkit](https://github.com/mansi-sharma123/AI-Career-Toolkit)
4. File: app.py -> Secrets me API key daalo -> Deploy!
