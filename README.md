### 🌟 About The Project

**AI-Career-Toolkit** is an AI-powered toolkit that helps you save 10+ hours every week. Upload your resume to get ATS score, or paste a YouTube link to get a full summary in seconds.

### ✨ Features

| Feature | Details |
| :--- | :--- |
| 📄 AI Resume Analyzer | ATS Score / 100, Missing Keywords, Improvement Tips |
| 🎥 AI YouTube Summarizer | Transcript + AI Summary + Key Takeaways |
| 💼 Coming Soon | Cover Letter Generator, LinkedIn Optimizer |

### 🛠️ Tech Stack

Language: Python | Frontend: Streamlit | AI: OpenAI GPT-4, Gemini, LangChain | Tools: PyPDF2, Youtube-Transcript-API

### ⚙️ Installation

1. Clone the repository - `git clone https://github.com/mansi-sharma123/AI-Career-Toolkit.git`
2. Go to folder - `cd AI-Career-Toolkit`
3. Install all packages - `pip install -r requirements.txt`
4. Add your API key in .env file - `OPENAI_API_KEY=your_key_here`
5. Run the app - `streamlit run app.py`

### ☁️ Deployment Guide

1. Go to **[share.streamlit.io](https://share.streamlit.io)** and login with GitHub
2. Click **New App** and select this repository
3. Main file path: **app.py**
4. Add API Key in **Secrets** and Deploy!
