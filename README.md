## 🌟 About The Project

**AI-Career-Toolkit** is built for students and job seekers who waste hours in resume rejection and watching long tutorials.

> This toolkit analyzes your resume like a real ATS and summarizes any YouTube video in 10 seconds using Generative AI.

### 🎯 Problem It Solves
- ❌ Resume fails in ATS , not get shortliste

- ✅ Solution: AI se instant ATS Score 

---

## ✨ Key Features

### 📄 AI Resume Analyzer
- Upload PDF Resume
- Get **ATS Score / 100**
- Find Missing Keywords & Skills Gap
- Formatting Mistakes Detection
- GPT-4 Powered Improvement Suggestions

### 🎥 AI YouTube Video Summarizer
- Just Paste YouTube Link
- Auto Transcript Fetch using `youtube-transcript-api`
- AI Summary in 5 Points + Key Takeaways
- Save 90% Learning Time

### 💻 Web App - `app.py`
- Clean Streamlit UI
- Both tools in one place
- Mobile responsive

⚙️ Installation & Setup

1. Clone the repo

git clone https://github.com/mansi-sharma123/AI-Career-Toolkit.git
cd AI-Career-Toolkit

2. Install dependencies

pip install -r requirements.txt

3. Add your API Key
Create a `.env` file in root folder:

OPENAI_API_KEY=your_openai_key_here
GOOGLE_API_KEY=your_gemini_key_here

4. Run the app

streamlit run app.py

---

☁️ Deployment Guide

You can deploy for FREE in 2 minutes:

1. Go to *[share.streamlit.io](https://share.streamlit.io)*
2. Login with GitHub
3. Click *New App* -> Select Repo: `mansi-sharma123/AI-Career-Toolkit`
4. Main file path: `app.py`
5. Go to *Advanced Settings -> Secrets* and add your API keys
6. Click *Deploy!*
