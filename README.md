## 🌟 About The Project
Built for students whose resumes fail in ATS screening.

> Upload resume → Get ATS Score / 100 → Fix Keywords → Get Shortlisted

## ✨ Features
- 📄 Upload PDF Resume
- 📊 ATS Score / 100
- 🔍 Missing Keywords Detection
- 🛠️ Formatting Mistakes Fix

## ⚙️ Installation & Setup
**1. Clone the repo**

git clone https://github.com/mansi-sharma123/AI-Career-Toolkit.git
cd AI-Career-Toolkit

*2. Install dependencies*

pip install -r requirements.txt

*3. Add API Key*
Create `.env` file and add:

OPENAI_API_KEY=your_key_here

*4. Run the app*

streamlit run app.py
