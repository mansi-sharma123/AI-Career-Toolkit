# AI-Career-Toolkit 🚀
By Mansi Sharma | LLM Apps College Project

An AI-powered toolkit to analyze resumes and guide career growth using Google Gemini.

### Features
✅ Resume Score (e.g., 68/100) 
✅ Strength & Skill Gap Analysis
✅ Handles Gemini 503 busy error with auto-fallback models

### Tech Stack
Python, Streamlit, PyPDF2, Google GenAI (Gemini 1.5 Flash / 2.0 Flash)
